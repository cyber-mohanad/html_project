# Course12

A professional training course landing page built with HTML5 and CSS3, showcasing fundamental front-end web development skills.

## Project Overview

Course12 is a front-end development project focused on structuring and styling a course landing page for a computing basics training program. The project demonstrates practical experience with HTML structure, CSS styling, website layout organization, navigation menus, tables, forms, and user interface design. It was built as part of a hands-on learning exercise in creating clean, organized, and visually appealing web pages using only core web technologies.
